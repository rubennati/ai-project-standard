## Licence

**Not chosen yet.** Until a `LICENSE` file exists, nobody may legally use,
modify or redistribute this — publishing the code changes nothing about that.
CI fails until you add one.

Three that cover most cases:

| Licence | Choose it when |
|---|---|
| **MIT** | You want the widest possible use and do not care what people do with it |
| **Apache 2.0** | Same, but you want an explicit patent grant — the usual choice where companies are involved |
| **MPL 2.0** | You want changes to your files published, while allowing your code inside larger proprietary products |

Take the full text from <https://opensource.org/licenses>. Do not write your own.

Longer comparison: <https://ai-standard.rubennati.at/open-source/choosing-a-licence>
