# Documentation

- Say what is true, once, in the place a reader looks first. Duplication drifts.
- Documentation lands in the same change as the behaviour it describes.
- State claims about the outside world with a source and the date it was
  checked. Vendor behaviour changes without announcement.
- Prefer a table over three paragraphs, and an example over a description.
- Delete documentation that is no longer true. Stale docs are worse than none —
  they are trusted.
