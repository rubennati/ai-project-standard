# Collaboration Loops

**Plan** — objective, scope, constraints, expected output, stated before editing.

**Implement** — small scoped changes on one branch, with traceable notes.

**Verify** — run the gates and show the output. Unrun is unverified.

**Review** — a pull request that explains why. The diff shows what.

**Compress** — at the end of a session, leave enough in the pull request that
the next session resumes from it rather than from memory.

**Retrospect** — when something went wrong in the process rather than the code,
record it in `errors.md` and change the rule that allowed it.
