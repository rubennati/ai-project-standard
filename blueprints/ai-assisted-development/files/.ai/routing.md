# Routing Guide

Load the minimum context for the task at hand. Reading everything wastes the
window and buries the part that mattered.

Always: `project-brief.md`, `state.md`.

Then, by kind of task:

- **Coding** — `rules.md`, `domains/coding.md`, `quality-gates.md`,
  `secure-development.md`
- **Documentation** — `rules.md`, `domains/documentation.md`
- **Review** — `tasks.md`, `quality-gates.md`, `risks.md`
- **Security** — `secure-development.md`, `risks.md`, `domains/testing.md`
- **Architecture** — `domains/architecture.md`, `decisions.md`, `rules.md`
- **Release** — `domains/release.md`, `quality-gates.md`
- **Continuing or resuming work** — `tasks.md` for what is queued,
  `progress.md`, and the open branch with its pull request

Add an entry when a new kind of task appears. Delete one when it stops
happening.
